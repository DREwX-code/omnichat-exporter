# Usage Guide

This guide explains how to use OmniChat Exporter to export AI conversations from supported platforms.

## Overview

OmniChat Exporter lets you export AI conversations directly from the browser.

You can export:

- Full conversations
- Individual messages
- Conversation metadata
- Text content
- Code blocks
- AI-generated images when supported
- Multilingual conversations

Available export formats:

- TXT
- Markdown
- JSON
- PDF

## Step 1 — Open a Supported Conversation

Open a conversation on one of the supported platforms:

- ChatGPT
- Gemini
- Claude
- Grok
- DeepSeek

Make sure the conversation is fully loaded before exporting.

## Step 2 — Use the Export Button

Once OmniChat Exporter detects a supported conversation page, an export button will appear in the interface.

Click the export button to open the export options.

## Step 3 — Choose What to Export

Depending on the platform and page layout, you can export:

### Full Conversation

Exports the entire visible conversation.

Best for:

- Backups
- Archives
- Research notes
- Long conversations
- Project documentation

### Individual Message

Exports a single selected message.

Best for:

- Saving one useful answer
- Reusing code
- Keeping a short note
- Sharing a specific response

## Step 4 — Choose an Export Format

Choose the format that matches your use case.

| Format | Best for |
|---|---|
| TXT | Simple readable backups |
| Markdown | Notes, documentation, GitHub, Obsidian |
| JSON | Structured data, automation, processing |
| PDF | Sharing, printing, long-term archiving |

## Exported Metadata

OmniChat Exporter may include metadata such as:

- Conversation title
- Export date
- Platform name
- Conversation URL
- Message roles
- Message order

Metadata helps keep exported conversations organized and traceable.

## PDF Export Notes

PDF export is designed for readable and shareable documents.

PDF generation may require additional rendering resources for:

- Multilingual text
- Special characters
- Mixed writing systems
- AI-generated images
- Complex formatting

If a PDF export looks incomplete, reload the page and try again after the conversation is fully loaded.

## Markdown Export Notes

Markdown export is useful for:

- Documentation
- GitHub repositories
- Obsidian vaults
- Notes apps
- Blog drafts
- Knowledge bases

Code blocks are preserved when possible.

## JSON Export Notes

JSON export is useful for:

- Developers
- Automation
- Data processing
- Local archives
- Conversation analysis

The JSON output is designed to keep conversation content structured and reusable.

## Best Practices

Before exporting:

- Let the full conversation load
- Expand hidden or collapsed content if needed
- Wait for images to finish loading
- Avoid exporting while a response is still generating
- Refresh the page if the export button does not appear

## Limitations

AI platforms may update their interface at any time.

If a platform changes its layout, OmniChat Exporter may need an update to restore full compatibility.
